# Senior Skills → PRIVATE Project Manager: V2 daily plans

This is a real **read-only daily planning CLI**, not a 24/7 Codex runner or a scheduler. It never contacts Codex or GitHub, changes queue files, commits to target apps, or starts paid services. The local private manager state retains the only execution authority.

## Owner workflow

1. Ask the public senior conductor to conduct 20 Arabic questions for a new app or significant architecture change. Store the answers in a PRIVATE directory. Small pre-approved maintenance tasks do not need a retroactive questionnaire.
2. Run the public blueprint command to receive a provisional architecture, documented alternatives, risks, a dependency-ordered task graph, and a concept-image brief. Unknowns remain explicitly unknown.
3. Review two or three relevant open-source GitHub candidates at immutable commits, licensing including assets, actual features, maintenance and hosting. Verify dated provider quotes at ordinary, peak and recovery loads. Missing quotes never count as free.
4. Arrange four genuine reviews (feasibility, architecture, security and design) and create the public packet only after real inspectable SHA-256-bound evidence exists.
5. Use the existing PRIVATE packet reconciler. It must return READY_FOR_MANAGER_REVIEW. A valid packet is not permission to merge, spend, deploy or process real sensitive data.
6. Generate a proposed timetable:

    python manager/scripts/plan_reviewed_day.py --packet /PRIVATE/manager-handoff.json --evidence-dir /PRIVATE/reviews --manager-root manager/.state --start 2026-10-18T09:00:00+03:00 --minutes 240 --milestone-minutes 60 --review-minutes 15 --out /PRIVATE/day-plan.json

7. The planned timestamps are **illustrative UTC work slots**, not actual calendar reservations or executed Codex tasks. The tool cannot wake or reauthorize Codex. A real supervisor must check the latest GitHub PR/issue/CI, quota and human approval for every action.
8. At most one implementation is active globally. Do not reopen any PAUSED_BY_OWNER, BLOCKED, IN_PROGRESS or AWAITING_HUMAN_REVIEW work automatically. When work stops, checkpoint and re-inspect another eligible project; do not merge the old PR to unlock the next task.

## Gate guarantees and limits

The read-only planner re-checks packet structure, real review file hashes, exact repository registration in the queue, duplicates and dependency order. It produces a maximum eight-hour *proposed* work budget, with separate review time. Other projects listed are **read-only failover candidates**, not authorization to execute.

A SHA-256 match does not establish true reviewer independence, the truth of provider quotes, real GitHub state or production security. Successful fake Auth or browser integration tests cannot replace tests against actual provider accounts. No periodic scheduler or Codex integration is installed by this PR; such wiring needs a supported runtime and must respect usage limits.

Do not upload owner interview details, medical/customer records, keys or actual private evidence to the public Senior Skills repository.

It does not redistribute copyrighted books and does not confuse book-inspired advice with actual testing. Refer to the public docs/sources.md and config/senior-gates.json files.
